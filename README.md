# 🏠 Today Housing (투데이하우징)

**네이버 부동산·다방 도면을 자동으로 3D로 바꾸고, 무료 AI(Gemma)의 실시간 도움을 받아 가구를 배치·게시하는 캡스톤 프로젝트**

오늘의집과 비슷하지만, 가구 배치 화면에서 무료 AI가 실시간으로 배치를 도와준다는 점이 다릅니다.

## 만들 기능 (기획)

1. 네이버 부동산/다방에서 도면(이미지)을 가져오기
2. 도면의 벽만 인식해 자동으로 3D 모델로 변환
3. 3D로 만든 공간에 미리 준비된 에셋(카테고리별 5개)을 2D 화면에서 배치
4. 배치가 끝나면 "완료" 버튼으로 웹사이트에 게시
5. 다른 사용자에게 댓글로 의견 받기

## 폴더 이름 규칙 (CAMPUS AX-TON 템플릿 기준)

- 이 폴더는 팀 프로젝트용으로 `today housing`이라는 이름을 사용합니다.
- 앞으로 새 기능을 추가할 때도 이 폴더를 계속 사용합니다 (재복사 없이 이어서 작업).

## 시작하기

터미널(Claude Code를 여는 창)에서 순서대로 입력합니다.

```bash
cd "today housing"
```

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 **http://localhost:3000** 을 열어 🏠 화면이 보이면 성공입니다.

## 자주 막히는 지점

| 증상 | 확인할 것 |
|---|---|
| `npm: command not found` | Node.js 설치가 안 된 상태입니다. 브릿지 가이드의 Node.js 설치 단계를 다시 진행하세요. |
| `npm install` 이 멈춰 있음 | 와이파이 상태를 확인하고, 1~2분은 원래 걸립니다. |
| localhost:3000 이 안 열림 | `npm run dev` 를 실행한 터미널 창을 닫지 않았는지 확인하세요. |
| 화면이 이상하게 깨짐 | 터미널에서 `Ctrl+C` 로 서버를 끄고 `npm run dev` 를 다시 실행하세요. |

## 만든 것

- [Next.js](https://nextjs.org) 최소 구성 (화면 1개)
- 데이터 저장이 필요하면 localStorage부터 시작합니다

## 참고

- 도면 3D 변환 인터랙티브 프로토타입(단독 실행 HTML)은 별도로 전달받은 `plan3d.html` 파일을 참고하세요.
- 네이버 부동산 실데이터 확보는 이름 검색이 아니라 **도면 이미지 URL 붙여넣기** 방식으로 진행하기로 했습니다 (네이버 봇 탐지 이슈).
